MrWhoOidc

A lightweight, standards-compliant OpenID Connect identity provider built on .NET.

Explore Features View on GitHub
Standards Compliant

Implements OpenID Connect Core, Discovery, Dynamic Registration, and OAuth 2.0 extensions including PKCE, PAR, DPoP, and Token Exchange.

Multi-Tenant

First-class multi-tenancy with isolated realms, clients, scopes, and roles per tenant. Manage everything through the admin UI or the CLI.

Developer Friendly

Built on .NET with Aspire for local development. Includes a CLI tool, example apps, and comprehensive E2E test coverage.

Customer Portal

A lightweight portal shell is now available for signed-in customers to review licenses, requests, and payment records through the future licensing platform.

Quick Start

# Clone the repository
git clone https://github.com/popicka70/MrWho.git
cd MrWho

# Run with .NET Aspire
dotnet run --project MrWhoOidc.AppHost

# Or run with Docker Compose
docker compose up -d

See the GitHub repository for full documentation and guides.
