Quick start overview

Up and running in three steps.

1

Clone MrWho & Configure

Clone the public deployment repo, not the source repo, then generate a TLS certificate and set the local environment.

2

Bootstrap Your Tenant

Start Docker Compose, seed the first tenant, and confirm discovery works.

3

Verify & Explore

Check discovery and JWKS, then configure clients and scopes in the Admin UI.
