Roadmap

Customer Portal

This page outlines the planned customer portal. It is not yet a production-authenticated application — it documents the intended direction.

MrWhoOidc handles authentication. MrWhoLicensing will be the source of truth for organizations, licenses, requests, entitlements, and payment records.

Current status

Public roadmap page only. No production customer data is loaded, and no real portal session is established.

Intended API surface

  • GET /api/organizations
  • GET /api/license-requests
  • GET /api/payment-records
  • POST /api/license-requests

Authentication model

Planned authority:

https://mrwho.onrender.com/t/default

Authorization Code + PKCE with backend API integration.

Next steps

  • Create a real portal client registration
  • Implement Authorization Code + PKCE correctly
  • Exchange the code server-side and validate tokens
  • Call MrWhoLicensing APIs for organizations, licenses, requests, and payments
  • Add proper session handling, logout, and error states
