Prototype

Customer portal roadmap page

This page is intentionally presented as a prototype and scope summary. It is not yet a production-authenticated customer portal, and it does not currently run a complete sign-in flow.

Public prototype only
The intended production direction is: MrWhoOidc handles authentication, while MrWhoLicensing becomes the source of truth for organizations, licenses, requests, entitlements, and payment records.

Current status

Public prototype only. No production customer data is loaded here, and no real portal session is established from this page.

Intended API surface

  • GET /api/organizations
  • GET /api/license-requests
  • GET /api/payment-records
  • POST /api/license-requests

Authentication model

Planned authority:
