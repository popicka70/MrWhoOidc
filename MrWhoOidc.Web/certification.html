About the OIDC Certification Program

The OpenID Connect Certification Program is the official conformance testing program run by the OpenID Foundation. It verifies that an OpenID Connect implementation correctly follows the OpenID Connect Core 1.0 specification.

In OpenID Foundation terminology, self-certification is a formal declaration that a specific deployment conforms to a conformance profile through conformance testing. The downloadable package on this page is the published evidence from that testing for the Basic OP profile.

These test results were generated by the official OpenID Foundation conformance suite. The result export itself is not the certified deployments directory; for the official certification listings and program details, visit openid.net/certification.
