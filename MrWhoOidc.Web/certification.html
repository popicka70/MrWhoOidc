About the OIDC Certification Program

The OpenID Connect Certification Program is the official conformance testing program run by the OpenID Foundation. It verifies that an OpenID Connect implementation correctly follows the OpenID Connect Core 1.0 specification and related logout specifications.

In OpenID Foundation terminology, self-certification is a formal declaration that a specific deployment conforms to a conformance profile through conformance testing. The downloadable packages on this page are the published evidence from that testing for the Basic OP, RP-Initiated Logout OP, Front-Channel Logout OP, and Back-Channel Logout OP profiles.

These test results were generated by the official OpenID Foundation conformance suite. The result exports themselves are not the certified deployments directory; for the official certification listings and program details, visit openid.net/certification.
