About the project

An OIDC provider written from scratch on .NET 10.

MrWhoOidc is an open-source identity provider for teams that want full control over their authentication stack — without relying on heavyweight frameworks or vendor lock-in.

Why MrWhoOidc?

Most .NET identity solutions wrap a heavyweight library that hides protocol details behind abstractions. MrWhoOidc takes the opposite approach: every OIDC flow is implemented directly against the specifications, so you can read the code and see exactly what your identity provider does.

If your team needs to understand, debug, or extend auth code exchange, token binding, or key rotation — MrWhoOidc gives you that control without trading off production readiness.

Design Principles

Against the specs

OpenID Connect Core, Discovery, and the latest OAuth 2.0 security extensions — implemented directly.

Multi-tenant from the start

Isolated tenants, realms, and client configurations built into the core — not a plugin.

Docker-first

PostgreSQL for persistence, Docker Compose for deployment, .NET Aspire for local development.

Observable

OpenTelemetry OTLP export, structured logging, audit trails, and Application Insights support.

Technology Stack

MrWhoOidc is built on .NET 10, uses EF Core with PostgreSQL, and ships with a CLI tool (mrwho-cli) that includes an MCP server for AI agents, a full admin UI, and example client applications in .NET, React, and Go.

Deployment is supported via Docker Compose with production-ready templates, TLS certificate generation scripts, and a one-time bootstrap flow for first tenant creation.
