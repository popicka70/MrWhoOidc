About the project

Identity infrastructure, built transparent.

MrWhoOidc is an open-source identity provider for teams that want full control over their authentication stack — without heavyweight frameworks or vendor lock-in.

Why MrWhoOidc?

Most .NET identity solutions rely on heavyweight libraries that abstract away protocol details. MrWhoOidc takes a different approach: every OIDC flow is implemented directly against the specifications, giving you full transparency into what your identity provider actually does.

If your team needs to understand, debug, or extend every aspect of auth code exchange, token binding, or key rotation — MrWhoOidc gives you that control without trading off production readiness.

Design Principles

Standards first

Strict adherence to OpenID Connect Core, Discovery, and the latest OAuth 2.0 security extensions.

Multi-tenant by default

Isolated tenants, realms, and client configurations from day one.

Operationally simple

PostgreSQL for persistence, Docker Compose for deployment, .NET Aspire for local development.

Observable

OpenTelemetry instrumentation, structured logging, and audit trails for full operational visibility.

Technology Stack

MrWhoOidc is built on .NET 10, uses EF Core with PostgreSQL, and ships with a CLI administration tool (mrwho-cli), a full admin UI, and example client applications in C#, React, and Go.

Deployment is supported via Docker Compose with production-ready templates, TLS certificate generation scripts, and a one-time bootstrap flow for first tenant creation.
