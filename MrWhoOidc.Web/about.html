Project context

About MrWhoOidc

MrWhoOidc is an open-source OpenID Connect and OAuth 2.0 identity provider built from the ground up on .NET. It is designed for teams that want full control over their identity infrastructure without depending on large third-party frameworks.

Why MrWhoOidc?

Most .NET identity solutions rely on heavyweight libraries that abstract away protocol details. MrWhoOidc takes a different approach: every OIDC flow is implemented directly against the specifications, giving you transparency into what your identity provider actually does.

Design Principles

  • Standards first — strict adherence to OpenID Connect Core, Discovery, and the latest OAuth 2.0 security extensions (DPoP, PAR, JARM, Token Exchange).
  • Multi-tenant by default — isolated tenants, realms, and client configurations from day one.
  • Operationally simple — PostgreSQL for persistence, Docker Compose for deployment, .NET Aspire for local development.
  • Observable — OpenTelemetry instrumentation, structured logging, and audit trails that make operator behavior easier to inspect.

Public install model

The public repository is intended to get evaluators from clone to a working first tenant using explicit Docker setup, a one-time bootstrap, and tenant-scoped smoke tests. This site now reflects that workflow instead of implying that a blank database becomes usable by itself.

Technology

MrWhoOidc is built on .NET 10, uses EF Core with PostgreSQL, and ships with a CLI administration tool (mrwho-cli), a full admin UI, and example client applications in C#, React, and Go.

Open Source

The project is developed in the open on GitHub. Contributions, issues, and discussions are welcome.
