Features

MrWhoOidc implements a broad set of modern identity protocols and management capabilities.

OpenID Connect & OAuth 2.0

  • Authorization Code + PKCE
  • Client Credentials
  • Device Authorization (RFC 8628)
  • Token Exchange (RFC 8693)
  • CIBA (Client Initiated Backchannel Auth)
  • On-Behalf-Of flows
  • Refresh Token Rotation
  • Discovery & JWKS endpoints

Security Extensions

  • DPoP (Demonstrating Proof-of-Possession)
  • PAR (Pushed Authorization Requests)
  • JAR (JWT Secured Authorization Requests)
  • JARM (JWT Authorization Response Mode)
  • Back-Channel Logout
  • Automatic Key Rotation
  • Multi-secret client credentials
  • WebAuthn / Passkeys (FIDO2)

Multi-Tenancy & Administration

  • Tenant isolation with separate realms
  • Admin UI for clients, scopes, roles, users
  • Platform admin dashboard
  • External identity provider federation
  • Consent management
  • Configuration audit logging
  • Rate limiting per endpoint

Developer Experience

  • CLI tool (mrwho-cli) for automation
  • .NET Aspire integration for local dev
  • Docker Compose deployment
  • PostgreSQL persistence (EF Core)
  • OpenTelemetry observability
  • Example apps (Blazor, Razor, React, Go)
  • Comprehensive E2E test suite
