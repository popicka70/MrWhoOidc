# Page: Account Overview
## Route: /account

## Expectations
- Page heading "My Account" or "Account Overview" with a person icon
- Navigation tabs or sidebar links to sub-sections: Profile, Emails, Security/Password, MFA, Sessions, Linked Accounts
- Summary of user info: username, email, display name, tenant memberships
- Quick-action cards or links for the most common tasks (change password, manage sessions, etc.)
- If no active sessions or linked accounts, friendly counts shown (e.g., "2 active sessions")

## Actions
- Verify page loads without errors
- Verify all sub-section navigation links exist and are clickable
- Verify username/email of the logged-in user is displayed

## Visual Checks
- Page uses the full-width admin/account layout (sidebar or top nav present)
- Sub-section links use Phosphor icons matching their topic
- Active sessions and linked accounts show counts as badges
- Profile summary card is clearly styled and separated from navigation
