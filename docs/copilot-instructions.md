# Contributor and Assistant Instructions

The canonical repository guidance is [.github/copilot-instructions.md](../.github/copilot-instructions.md). Maintain architectural rules, primary-key conventions, migration commands, and test expectations there rather than duplicating them in this documentation folder.

The unique entity-ID convention from the former copy has been consolidated into the canonical instructions. Unsupported numeric performance claims were not carried forward. The warning guidance now distinguishes new warnings from pre-existing issues to keep unrelated changes out of a task.

This page is a navigation pointer, not a second agent customization. Use the [documentation index](index.md) for installation and operations and [documentation status](documentation-status.md) for historical plans and reviews.
